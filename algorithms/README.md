# Алгоритмы

Решения задач LeetCode и Codeforces.

- `leetcode/` — имя файла: номер и название задачи, например `0001_two_sum.py`
- `codeforces/` — имя файла: номер контеста и буква задачи, например `4A_watermelon.py`

В начале каждого решения — комментарий с идеей и сложностью по времени и памяти.
