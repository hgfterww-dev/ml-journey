# 1. Векторы

Источник: 3Blue1Brown, «Essence of Linear Algebra», видео 1.

## Главное

- На вектор можно смотреть тремя способами: стрелка в пространстве (физика), список чисел (программирование), любой объект, который можно складывать и умножать на число (математика).
- В линейной алгебре вектор обычно начинается в начале координат. Тогда его координаты `[x, y]` однозначно задают конец стрелки.
- **Сложение:** отложить второй вектор от конца первого. В координатах складываем покомпонентно: `[1, 2] + [3, -1] = [4, 1]`.
- **Умножение на число (скаляр):** растягивает или сжимает вектор, отрицательное число разворачивает. В координатах: `2 * [3, 1] = [6, 2]`.
- Почти вся линейная алгебра строится на этих двух операциях.

## Проверка на NumPy

```python
import numpy as np

v = np.array([1, 2])
w = np.array([3, -1])

print(v + w)   # [4 1]
print(2 * v)   # [2 4]
```
